PNMF ONE-CLICK START (WINDOWS)

1. Double-click Launch_PNMF.cmd.
2. On the first run, wait while the private .venv is created and dependencies
   are installed.
3. PNMF opens automatically at http://localhost:8501.

Later launches reuse the installed environment and start much faster.
Keep the launcher window open while using PNMF; close it to stop the server.

PowerShell alternative:

  .\pnmf.ps1

Advanced commands such as .\pnmf.ps1 test and .\pnmf.ps1 physics also install
or update the environment automatically when needed.

Supported learned models: et (default), rf.
Component physics is an independent SEL/LAmax screening route.

In Aircraft Designer:
1. Select a shared aircraft preset or enter a custom aircraft.
2. Choose learned only, physics only, or compare learned + physics.
3. Run the analysis. In compare mode, set the event inputs below the learned
   result and run component physics to see both noise curves together.
4. Read the live calculation log below each run button to see every learned
   metric/operation table and each major component-physics calculation stage.
